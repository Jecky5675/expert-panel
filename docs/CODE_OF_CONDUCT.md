# Code of Conduct

Contributors and users must communicate respectfully, review claims and changes on their evidence, and avoid harassment, discrimination, threats, doxxing, or disclosure of private information. Technical disagreement is welcome; personal attacks are not.

Report conduct or security-sensitive issues privately to the project owner rather than posting personal or secret information in a public issue. Maintainers may edit or remove abusive contributions and restrict participation when necessary to protect participants and the project.

This conduct policy governs collaboration. It is not an analytical role or an ethical-decision module in the Expert Panel workflow.
