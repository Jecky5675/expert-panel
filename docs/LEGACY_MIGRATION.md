# Legacy consolidation record

Before removing the v8–v25.9.2 archives, their entry instructions, references and scripts were compared with the v27 canonical package.

| Legacy behavior/artifact | v27 disposition |
|---|---|
| QUICK/STANDARD/DEEP panel, independent first cards, evidence ledger, conflict classes, adversary, synthesis and pre-mortem | Retained in `SKILL.md`, `references/deliberation_quality.md`, `references/evidence_and_research.md`, and optional `references/legacy_capabilities.md`. |
| Keyword persona generator `panel_init.py` | Replaced by the smaller evidence-bounded `scripts/role_orchestrator.py` and tested role cases; it plans roles but does not run them. |
| Full S1–S7 deliberation | Retained as an optional deep protocol rather than mandatory ceremony. |
| Audience modes ELI5/TLDR/Feynman/Jargonize/Humanize/Sources | Retained in `references/legacy_capabilities.md` with no fabricated citations. |
| Hypotheses, research artifacts and detailed finding registry | Retained in current evidence method, ledger templates and `assets/deep_review_template.md`; optional Research First overlay is attributed under `vendor/`. |
| Universal Markdown/TXT/PDF and ChatGPT copy | Replaced by single-source `scripts/universal_installer.py` with direct Markdown export and reproducible `portable/` editions. |
| README, Humanizer, Prompt Engineer, Security Review, upstream maintenance, knowledge links | Retained and extended from v25.9.2. |
| Beginner path and project review | Added as first-class routes with an attributed MethodWeft snapshot and explicit evidence/permission boundaries. |
| Web role simulation versus actual agent delegation | United into `references/host_profiles.md` and `scripts/universal_installer.py`; no duplicate platform trees. |
| Ethical/SCRIBE role and ethics knowledge/personas | Deliberately removed at the owner's request; not a preserved capability. |
| Old generated HTML, PDFs, reports, duplicate ZIP trees and temporary files | Not retained; these are stale build artifacts or duplicated packages. |

Deterministic gates cover route regressions, role selection, profile wording, removed-role absence, links, portable reproduction, package integrity and clean extraction. These checks establish structural/behavioral preservation of the documented workflows; they do not prove that every future model answer is correct.
