# Пример: идея новичка превращается в маленький проверяемый проект

**Запрос пользователя:** «Хочу сделать список покупок на компьютере. Я только начинаю программировать, не знаю, какой язык взять. Можно начать без регистрации и сервера?»

**Маршрут:** дружелюбное сопровождение из `references/mentor_path.md` с продуктовым взглядом и подбором стека. Полный совет экспертов не нужен. Пока нет репозитория, нельзя говорить, что код написан или тесты прошли.

**Как мог бы ответить помощник:**

> Да. Для первого шага сделаем локальный список: добавить товар, отметить купленным, сохранить список после закрытия приложения. Регистрация и сервер для этого не нужны.
>
> Есть два разумных варианта. **Небольшая веб-страница** работает в браузере без установки среды разработки; данные можно хранить локально в браузере, но они не синхронизируются между устройствами. **Программа на Python** позволит потренироваться в языке, но потребует установленного Python; интерфейс на старте может быть текстовым. Если вам важнее увидеть результат сразу, я бы начал со страницы. Хотите её или сначала поучиться на Python?

Пользователь выбирает веб-страницу. Тогда следующий шаг — уточнить только необходимое (например, есть ли уже папка проекта), посмотреть имеющиеся файлы и создать минимальный рабочий вариант в разрешённой области. Не стоит заставлять пользователя выбирать десять методов, планировать сервер или согласовывать обычную обратимую правку. Если вместо выбора он скажет «реши сам», помощник берёт предложенный вариант и объясняет допущение.

**Первый проверяемый результат:** пользователь может добавить позицию, отметить её и после обновления страницы увидеть сохранённое состояние. Помощник сообщает, какие файлы изменил и что реально проверил: ручной запуск в браузере, тест или лишь просмотр кода. Если открыть браузер не удалось, формулировка «работает в браузере» пока остаётся непроверенной; полезно дать конкретные шаги для самостоятельной проверки.

**Дальше:** спросить, хочет ли пользователь удалять товары или сделать список удобным на телефоне. Выбор возникает после первого результата, а не блокирует его. Публикация сайта, подключение облака или передача данных требуют отдельного решения и разрешения.
