## v25.6.0 composability and deliberation review

The public package now prefers exact installed specialist skills over local snapshots:

- `HUMANIZE` delegates to `humanizer` when the host can verify and invoke it.
- `README_STUDIO` delegates to `beautify-github-readme` when the host can verify and invoke it.
- Bundled snapshots remain complete fallbacks for portable and generic hosts.

Comparable open skills reviewed during this cycle included `zhjai/agent-arena`, its `deliberative-analysis` companion, and `ngmeyer/skills` `council-review`. Adopted ideas were limited to capability-safe patterns: real heterogeneity before role simulation, lossless task packets, non-obvious option generation, content-anonymous review, a mandatory “what did all responses miss?” question, ensemble baselines, reasoning-footprint overlap checks, and transparent degraded modes. Vendor-specific CLI commands, hardcoded model tiers, background orchestration, and claims of automatic independence were not copied.

Academic controls were cross-checked against research on divergent multi-agent debate, anonymous identity-bias reduction, and debate-versus-vote baselines. The resulting protocol treats debate as optional test-time work, not proof of correctness. No patent-derived method is included in this release. Patent status is not represented as a quality or originality claim.

## v25.7.1 P2P provenance and release-leak audit

No normalized line from the supplied P2P Markdown files is copied verbatim into the current Expert Panel Markdown corpus. Expert Panel does not redistribute the original P2P source files; it tracks the repository as a methodology source and reviews changes manually.

Public release hygiene now uses a strict path/extension allowlist and secret/path scan in addition to `.gitignore`. The packager and CI run this audit before packaging and after clean extraction.
