## Provenance and reuse boundary

- This inventory was prepared from selected local donor README/SKILL headers and two license files, not from a full donor audit. The MethodWeft local LICENSE identifies MIT with 2026 MethodWeft Skill contributors; `research-first-builder-main/LICENSE` identifies MIT with 2026 IT Shelter contributors. `python-pro` declares MIT in its SKILL header; a declaration is not verification of every nested asset. Other donor licenses, authorship, and transitive asset permissions have **not** been established by this inventory.
- Before copying or adapting any donor text, code, images, font, sample, or prompt: inspect the exact material, upstream provenance, license and attribution obligations for that item; update project notices and license records as appropriate. This document authorizes none of those actions. Favor independently written behavior descriptions over incorporation.
- `NOTICE.md`, `UPSTREAM_SOURCES.json`, `references/source_map.md`, and `references/upstream_integration.md` already track a different set of integrated sources. Do not silently add these donors to those records or characterize them as bundled, tested, or active. A directory on disk is not proof the host registered its skill, installed dependencies, or can run its CLI/MCP server.
- Never execute donor scripts, install dependencies, invoke paid integrations, retrieve private assets, or access network services merely because a README describes those capabilities. Use the host's actual skill registry and current authorization boundary if optional dispatch is warranted.
