# Decision Matrix

Score only after weights are agreed. Use 0–5 or another defined scale.

| Criterion | Weight | Option A | Evidence | Option B | Evidence | Option C | Evidence |
|---|---:|---:|---|---:|---|---:|---|

## Hard constraints

- Any option violating a documented hard constraint is marked ineligible, not merely given a lower score.

## Sensitivity

- Recalculate with plausible weight ranges.
- Identify which criterion or assumption changes the winner.
- Preserve a tie when the evidence does not justify a single winner.
